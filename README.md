# mediatek-genio-supports

This snap provide supports for Ubuntu Core on MediaTek Genio devices.

# Support services included

* mdpd

  MDPD is a user-space driver for MediaTek's Media Data Path. Please refer to [here](https://mediatek.gitlab.io/aiot/doc/aiot-dev-guide/master/sw/yocto/app-dev/video/video-g350-evk.html#mdpd-daemon) for more information.

  MDPD is only applicable for mt8365 (G350) devices.

* vpud

  VPUD is a user-space driver for MediaTek Video Codec. Please refer to [here](https://mediatek.gitlab.io/aiot/doc/aiot-dev-guide/master/sw/yocto/app-dev/video/video-common.html#vpud-daemon) for more information.

  VPUD is applicable for mt8365 (G350), mt8188 (G510/G700), mt8189 (G520/G720), mt8395 (G1200) devices.
